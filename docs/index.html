Install

Download a file, drop it in My Shapes, then pick it up inside Visio. A vendor folder becomes a submenu.

  1. Download

    Save a stencil from the catalog, or take a whole vendor as a .zip from the vendor’s banner. The repository itself is also a single archive.

  2. Put it in My Shapes

    Place the file in Documents\My Shapes. Vendor subfolders work and show up as submenus.

  3. Open it in Visio

    In Visio, choose More Shapes > My Shapes and select the stencil.

Older .vss files and File Block

Very old .vss formats may be blocked by Visio’s File Block setting (Trust Center > File Block Settings). They can be opened by temporarily allowing them, then saved as .vssx.

In current Visio: File > Options > Trust Center > Trust Center Settings > File Block Settings. Allow the older binary stencil types, open the file, save it as .vssx, then turn the block back on if you want it.
